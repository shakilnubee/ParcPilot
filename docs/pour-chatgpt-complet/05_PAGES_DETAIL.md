## A. Cœur métier

### A.1 — `pages/vehicules.html` (~8225 l.)
1. **Rôle** : référentiel central de la flotte (liste/fiches, affectations, documents, QR, scan, envois).
2. **Actions** : nouveau véhicule ; édition inline ; suppression (restaurable/Corbeille) ; vues tableau/cartes/galerie 3D ; onglets par groupe (drag&drop) ; hub QR (afficher/PNG/imprimer) ; comparateur 2 véhicules ; « Compléter cartes grises » ; envois groupés (relevé km, accès QR, message, RDV) ; filtres + Réinitialiser.
3. **Formulaires/champs** : fiche véhicule (immat, marque, modèle, VIN, carburant, CO₂, puissance fiscale, masse G, crit'air, dates CT/révision/anti-pollution, boîte, couleur, autonomie, valeur achat/vente, loueur/propriétaire, assurance, entité/pays/mode de détention) ; affectations (conducteur, km début/fin) ; documents.
4. **Données affichées** : `data.vehicules` (cache/FP_DATA) + maps `FP.settings` keyées par plaque/id (km, masse, notes, affectations).
5. **Données enregistrées** : `vehicules` (CRUD), `documents`, `app_settings` (affectations/km/masse/notes), bucket `scans`.
6. **Fonctions JS** : `FP.galerie3d`, `FP.conducteurPicker`, `FP.searchSelect`, `FP.filterResetButton`, `FP.dupe`, `FP.scanIA`+`FP.CG_SCAN_PROMPT`, `FP.msg.open`, `FP.ensureJsPDF` ; locales `buildQrCanvas`/`renderQrCard`, `parkingParis`, `exportFichePDF`/`exportVentePDF`, `affectRowsHTML` (cf. `04`).
7. **Tables** : `vehicules`, `documents`, `app_settings`, storage `scans`.
8. **Relations** : socle de toutes les pages (clé immatriculation) ; chauffeur → `amendes.prenom` + `vehicules.chauffeur` ; affectations ↔ conducteurs ; docs ↔ factures/contrats/sinistres ; QR → `carte.html`/`v.html`.
9. **Automatisations** : alimente alertes/échéances (`FP.buildEcheances`) ; km alimente km-relance.
10. **Permissions** : lecture tous rôles ; CRUD données = gestionnaire+ ; config société non concernée ici.
11. **Desktop/mobile** : vues adaptatives, barre d'actions défilable sur mobile `[DOC règle mobile]`.
12. **Exports** : fiche PDF, fiche vente PDF, relevé PDF/Excel multi-colonnes, fiche groupe PDF.
13. **Cas particuliers** : stationnement gratuit Paris (`parkingParis`, critères officiels, « À vérifier » si doute) ; QR unique (3 sorties = 1 générateur `renderQrCard`) ; stockage autonomie↔`note_pneus`, version↔`type_pneus`.
14. **Limites/bugs** : aucun marqueur TODO/FIXME détecté `[VÉRIFIÉ]`. Scan en lot des cartes grises restant à finir pour une partie de la flotte `[DOC: tâche CLAUDE.md]`.
15. **Tests** : smoke Playwright (la page s'ouvre) ; calculs liés via `test-calculs.mjs`.

### A.2 — `pages/conducteurs.html` (~3457 l.)
1. **Rôle** : annuaire conducteurs (fiches, permis, documents, affectations), RGPD/PII fort.
2. **Actions** : CRUD conducteur ; galerie 3D ; recherche + reset ; scan permis + relecture en masse ; masquage permis ; message de bienvenue 3 canaux ; export PDF/CSV.
3. **Champs** : prénom, nom (2 champs séparés), adresse, date de naissance, tél, e-mail, permis (type/numéro/obtention/expiration/scan), note, poste, société.
4. **Données affichées** : `condCache` ← `FP.db.select('conducteurs')`, `FP.settings` (permisMasque, condDocs, congés via `FP.congesTable`), liens `data.vehicules`/`data.amendes`.
5. **Données enregistrées** : `conducteurs` (PK `key`), `documents`, `vehicules`/`amendes` (propagation), `app_settings`, storage `scans`.
6. **Fonctions JS** : `FP.conducteurs.*`, `FP.newConducteurModal`, `FP.conducteurPicker`, `FP.migrateCondKey`/`purgeCondKey`, `FP.scanIA('permis')`, `FP.msg.open` ; locales `applyRename`, `rereadPermisFromUrl` (cf. `04`).
7. **Tables** : `conducteurs`, `documents`, `vehicules`/`amendes`, `app_settings`, storage.
8. **Relations** : pivot affectations/amendes (prénom)/congés-péages (clé)/sinistres (responsable).
9. **Automatisations** : congés → détection conso pendant congé (Contrôle) ; permis → échéances.
10. **Permissions** : données = gestionnaire+ ; PII respectée (nettoyage export/cache `_PII_FIELDS`).
11. **Desktop/mobile** : cartes + galerie adaptatives.
12. **Exports** : PDF (aperçu/impression), CSV (sans PII).
13. **Cas particuliers** : renommage **propage** (`applyRename` + `FP.migrateCondKey` déplace congés/cartes/docs) ; RGPD strict.
14. **Limites/bugs** : aucun marqueur détecté `[VÉRIFIÉ]`. Bascule `key`→`id` stable non faite `[DOC]`.
15. **Tests** : smoke Playwright ; fusion-réglages/projection congés (unit).

### A.3 — `pages/amendes.html` (~3471 l.)
1. **Rôle** : avis ANTAI (import/scan, désignation, statut, paiement, e-mails). 2. **Actions** : ajout (anti-doublon), cycle de statut (payée/contestée/à payer/désignée), suppression restaurable, désignation, envoi 3 canaux, ZIP des avis par conducteur, export Excel/CSV/période. 3. **Champs** : plaque, prénom, n° d'avis, dates, 3 montants, motif, points, montant payé, commentaire, pièces. 4. **Affichées** : `data.amendes`, conducteurs (picker). 5. **Enregistrées** : `amendes`, `app_settings` (montant payé, watch justif), storage. 6. **JS** : `FP.dupe`, `FP.conducteurPicker`, `FP.searchSelect`, `FP.msg.open`, `FP.montantDu`/`estAPayer`, `FP.scanIA('amende')` ; locales `parseAvis`, `checkDoublonLive` (cf. `04`). 7. **Tables** : `amendes`, `conducteurs`(lecture), `app_settings`, storage. 8. **Relations** : conducteur, véhicule (`vehByImmat`), dashboard/stats (montants dus), `avis.html`. 9. **Automatisations** : montant dû (majoration selon date) → alertes amendes. 10. **Permissions** : données = gestionnaire+. 11. **Desktop/mobile** : tableau responsive. 12. **Exports** : Excel/CSV/période, ZIP PDF. 13. **Cas particuliers** : **3 montants** (minoré/forfaitaire/majoré), anti-`Math.max`, majoration par **titre** seulement, ré-import = doublon (pas majoration). 14. **Limites/bugs** : aucun marqueur détecté `[VÉRIFIÉ]`. 15. **Tests** : calculs amendes (`test-calculs.mjs`), smoke.

### A.4 — `pages/factures.html` (~3048 l.)
1. **Rôle** : factures fournisseurs + notes de frais + documents + fournisseurs. 2. **Actions** : 4 onglets, CRUD + corbeille, scan facture (+OCR notes de frais), mini-Drive documents, ZIP PDF par véhicule, export CSV. 3. **Champs** : date, fournisseur, n° facture, véhicule, HT/TVA/TTC, km, description, type, source/catégorie/conducteur (notes de frais). 4. **Affichées** : `data.factures`, `FP.db.select('documents')`. 5. **Enregistrées** : `factures`, `documents`, storage. 6. **JS** : `FP.scanIA('facture')`, `FP.dupe`, `FP.searchSelect`, `FP.conducteurPicker` ; locales `deriveTotals`, `ulysPdfToText`, `persistFacture` (cf. `04`). 7. **Tables** : `factures`, `documents`, storage, `app_settings`. 8. **Relations** : véhicule (coût/TCO), entretiens, sinistres (`type='sinistre'`), conducteur (notes de frais/Ulys). 9. **Automatisations** : coût exploitation → stats/budget/dashboard ; Ulys en-têtes via cron `ulys-daily`. 10. **Permissions** : données = gestionnaire+. 11. **Desktop/mobile** : onglets + tableaux responsives. 12. **Exports** : CSV (HT/TVA/TTC/Km), ZIP PDF. 13. **Cas particuliers** : contrôle HT+TVA=TTC (tolérance 0,02 €), lien Drive par `file_id`, notes de frais comptées au TCO. 14. **Limites/bugs** : migration colonnes notes de frais **en attente** (sinon source/catégorie/conducteur non persistés) `[VÉRIFIÉ]`. 15. **Tests** : calculs coûts (`test-calculs.mjs`), smoke.

### A.5 — `pages/entretiens.html` (~1165 l.)
1. **Rôle** : entretiens/révisions + garages. 2. **Actions** : tableau (factures filtrées), scan facture d'entretien, garages (scan + ajout prestataire + RDV), rappel 3 canaux, filtres+reset, export CSV. 3. **Champs** : date, véhicule, km, TTC, type, garage (nom/ville/tél/RDV). 4. **Affichées** : `data.factures` (filtre entretien), `data.vehicules`, garages (`FP.settings`). 5. **Enregistrées** : `factures`, `vehicules` (derniereRevision/kmDernierReleve), `app_settings` (garages), storage. 6. **JS** : `FP.scanIA('garage')`, `FP.searchSelect`, `FP.msg.open`, `FP.filterResetButton`. 7. **Tables** : `factures`, `vehicules`, `app_settings`, storage. 8. **Relations** : dérivé de `factures` ; met à jour `vehicules` → alertes révision/CT. 9. **Automatisations** : révisions → échéances/tâches auto. 10. **Permissions** : données = gestionnaire+. 11-13. responsive ; garages partagés avec `FP.getPrestataires`. 14. aucun marqueur détecté. 15. smoke + calculs.
